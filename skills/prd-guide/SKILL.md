# PRD 작성 가이드

러프한 아이디어를 AI 코딩 도구가 소비할 수 있는 구조화된 PRD로 변환하는 가이드.

## PRD 원칙

전체 템플릿: [prd-template.md](references/prd-template.md)

### AI 시대의 PRD

- **경량**: 1~5페이지. 50페이지 전통 PRD가 아님.
- **살아있는 문서**: 고정된 스펙이 아니라 프로젝트와 함께 진화.
- **What & Why 중심**: 기술 상세(How)는 포함하지 않음.
- **구조화**: AI 에이전트가 섹션별로 파싱할 수 있는 형식.
- **대화의 산물**: 사용자와 AI의 브레인스토밍 결과를 정리.

### PRD 구성 요소 (8 섹션)

| # | 섹션 | 핵심 질문 | 중요도 |
|---|------|----------|--------|
| 1 | 문제 정의 | 왜 이 제품이 필요한가? | 필수 |
| 2 | 타겟 사용자 | 누구를 위한 것인가? | 필수 |
| 3 | 핵심 기능 | 무엇을 제공하는가? (What, not How) | 필수 |
| 4 | NOT 리스트 | 무엇을 하지 않는가? | 필수 |
| 5 | 사용자 플로우 | 핵심 사용 시나리오는? | 필수 |
| 6 | 성공 메트릭 | 어떻게 성공을 측정하는가? | 권장 |
| 7 | 기술 제약 | 기술적 제한 사항은? | 권장 |
| 8 | 엣지 케이스 & 리스크 | 무엇이 잘못될 수 있는가? | 권장 |

## 브레인스토밍 → PRD 프로세스

### Phase 1: 핵심 파악 (필수 질문)

사용자에게 반드시 물어야 하는 질문들:

1. **문제**: "이 제품으로 해결하려는 핵심 문제가 뭔가요?"
2. **사용자**: "주요 사용자는 누구인가요? 어떤 상황에서 쓰나요?"
3. **가치**: "이 제품이 없으면 사용자는 어떻게 하나요? 왜 이게 더 좋나요?"

### Phase 2: 범위 설정 (구조화 질문)

핵심이 잡히면:

4. **기능**: "핵심 기능 3~5개를 꼽으면?"
5. **NOT 리스트**: "명확하게 하지 않을 것은?"
6. **플로우**: "사용자가 처음 접한 순간부터 목표 달성까지의 단계는?"

### Phase 3: 현실 확인 (검증 질문)

7. **성공**: "출시 후 3개월, 성공했다는 걸 어떻게 알 수 있나요?"
8. **제약**: "기술 스택, 예산, 일정에 제약이 있나요?"
9. **경쟁**: "비슷한 제품이 있나요? 차별점은?"
10. **리스크**: "가장 걱정되는 것은?"

### 질문 전략

- 한 번에 **2~3개씩** 질문 (10개를 한꺼번에 던지지 않음)
- 답변이 모호하면 **구체화 질문**으로 따라감
- 사용자가 "모르겠어"라고 하면 → **대안을 제시**하고 선택하게 함
- 충분한 정보가 모이면 → PRD 초안을 작성하고 피드백을 받음

## PRD ↔ Discovery 연결

PRD의 각 섹션이 Discovery 산출물로 변환된다:

| PRD 섹션 | Discovery 산출물 | 변환 방법 |
|----------|----------------|----------|
| 문제 정의 | Inception Deck Q1 (왜 여기 모였는가) | 직접 매핑 |
| 타겟 사용자 | 페르소나 | 사용자 유형을 페르소나로 확장 |
| 핵심 기능 + NOT 리스트 | Inception Deck Q3, Q4 | 직접 매핑 |
| 사용자 플로우 | Story Map의 Backbone | 플로우 → 활동 → 스토리 |
| 성공 메트릭 | Inception Deck Q8 | 직접 매핑 |
| 기술 제약 | Inception Deck Q7, Q10 | 솔루션 스케치 + 제약 조건 |
| 엣지 케이스 & 리스크 | Inception Deck Q9 | 리스크 매핑 |

## PRD 품질 체크리스트

- [ ] 문제가 구체적으로 정의되었는가 (모호한 표현 없이)
- [ ] 타겟 사용자가 구체적인가 ("모든 사람" 아님)
- [ ] 핵심 기능이 5개 이내로 집중되었는가
- [ ] NOT 리스트가 존재하는가 (범위 통제)
- [ ] 사용자 플로우가 step-by-step으로 서술되었는가
- [ ] 구현 방법(How)이 아닌 결과(What)를 기술하는가
- [ ] 1~5페이지 이내인가
